# Human review packet

Use this concise surface for a human gate. Keep citations, logs, run IDs, and supporting material in the work repository rather than adding sections here.

## Verdict

State the gate result in one line.

## Outcome and narrative

Lead with **What to review**: name the exact files, ref range, artifact, or rendered surface and list the one to three decisions or risks that need human attention. Say what response is needed. Then summarize what changed and why; do not make the human infer the review target from implementation details.

## Blocking issues

Include only when an issue prevents the requested gate. Omit this section from rendered output when there are no blocking issues.

## Decision and next action

Ask explicitly for approval or corrections on the named review target, then state the next safe action.
